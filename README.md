# Runhead AC website

Live site: https://runheadac.com/

Static HTML, CSS and JavaScript. GitHub Pages serves main from the repository root; .nojekyll disables Jekyll processing.

Run locally with `python3 -m http.server 8765`.

The previous website is preserved in branch `archive/old-site-2026-10-23` (commit `6b4dcaf`). Keep that branch as a historical backup; make future website updates on main.

The recovered design source is https://github.com/alexdaish/runhead-website-draft at commit f309240.

Content follow-ups: confirm current membership fees and registration dates in the external form, kit prices and order details, Tuesday pace groups, and weekend/trail plans with the club.
